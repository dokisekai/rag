# 06_会话持久化与测试评估

本文档解构 `services/history_service.py`（会话与引用 Chunk 持久化）、`services/notification_service.py`（系统通知）以及自动化测试评估套件（Workflow）。

---

## 🔄 会话落地与评估测试工作流程 (Persistence & Test Workflow)

```mermaid
flowchart TD
    subgraph SessionPersistence [会话历史增量落地流程]
        QAStart[用户发起 Q&A 问答] --> SaveInit[save_qa_session: 存入首问与 Session ID]
        QAFinish[流式回答完毕 / WebSocket 断开] --> UpdateSess[update_session: 更新 dialog_messages]
        UpdateSess --> AttachRef[绑定 rag_references (Chunk ID, 原文, 文件名)]
        AttachRef --> WriteHistory[写入物理磁盘 data/history.json]
    end
    
    subgraph EvaluationPipeline [RAG 效果评估测试流程]
        RunTest[运行 test_rag.py / test_raw_scores.py] --> LoadKB[加载测试知识库与 FAISS 索引]
        LoadKB --> InputTestQuery[输入标准测试 Query]
        InputTestQuery --> EvalVector[评估 FAISS 向量分值衰减]
        InputTestQuery --> EvalBM25[评估 BM25 得分及专有名词召回率]
        EvalVector --> Compare[输出混合检索梯度, 微调相似度阈值 & RRF 权重]
        EvalBM25 --> Compare
    end
```

---

## 💾 持久化文件结构

- 会话与 Chunk 引用表：`data/history.json`
- 系统未读通知表：`data/notifications.json`
- RAG 自动化测试脚本：`backend/test_rag.py`, `backend/test_raw_scores.py`, `backend/test_clean_query.py`
