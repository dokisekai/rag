# 03_文档解析与重叠切块

本文档介绍多格式文档解析器与切块引擎 `services/document_parser.py` 的架构设计与重叠切块工作流程（Workflow）。

---

## 🔄 文档解析与滑动切块工作流程 (Parser & Chunking Workflow)

```mermaid
flowchart TD
    File[用户上传文档字节流] --> Reg{DocumentParserRegistry 工厂注册中心}
    
    Reg -- .pdf --> PDFParser[PDFParser: PyMuPDF 启发式标题与页码提取]
    Reg -- .docx --> DOCXParser[DOCXParser: 标题样式识别与表格 Markdown 化]
    Reg -- .pptx --> PPTXParser[PPTXParser: Slide 提取与演讲者备注抓取]
    Reg -- .txt/.md --> TextParser[TextParser: chardet 自动识别编码解码]
    
    PDFParser --> Nodes[统一抽象节点列表 List[DocumentNode]]
    DOCXParser --> Nodes
    PPTXParser --> Nodes
    TextParser --> Nodes
    
    Nodes --> ChunkEngine[ChunkingEngine 滑动窗口切块]
    
    subgraph SlidingWindow [滑动窗口重叠切块逻辑]
        ChunkEngine --> ReadNode[读取段落节点]
        ReadNode --> CheckLen{节点字符数 > Chunk Size (500)?}
        CheckLen -- 否 --> AppendDirect[保留原始段落完整性]
        CheckLen -- 是 --> SplitOverlap[长文本切分: 保留 100 字符 Overlap 重叠区]
    end
    
    AppendDirect --> OutputChunks[输出格式化的 Chunk 列表]
    SplitOverlap --> OutputChunks
```

---

## 核心设计模式与细节

1. **`DocumentNode` 抽象节点**：
   使用 Python `@dataclass` 标准化多格式文档节点（`content`, `node_type`, `level`, `metadata`）。
2. **`TextParser` 自动编码判定**：
   通过 `chardet.detect(file_bytes[:4096])` 推断 UTF-8, GBK, GB2312 等编码，彻底消除中文乱码问题。
3. **表格结构保持策略**：
   DOCX Parser 与 PDF Parser 将表格行解析为 `| Column A | Column B |` 的 Markdown 表格，并保持单独 Node 完整性，防止数据断开。
