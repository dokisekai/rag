## 🔄 核心系统端到端工作流程 (End-to-End Workflow Diagrams)

### 1. 文档导入与向量构建流程 (Ingestion Workflow)

```mermaid
sequenceDiagram
    autonumber
    actor Admin as 管理员/用户
    participant API as FastAPI (main.py)
    participant Parser as DocumentParser Registry
    participant ChunkEngine as ChunkingEngine
    participant RagSvc as RagService
    participant FAISS as FAISS (index.index)
    participant Meta as metadata.json

    Admin->>API: 上传文档文件 (PDF/DOCX/PPTX/TXT)
    API->>Parser: 传入文件 Bytes 与文件名
    Parser->>Parser: 识别扩展名分发至对应解析器 (如 PDFParser)
    Parser-->>API: 返回抽象节点列表 List[DocumentNode]
    API->>ChunkEngine: 传入节点进行重叠切块 (Size=500, Overlap=100)
    ChunkEngine-->>API: 返回标准 Chunk 列表
    API->>RagSvc: 调用 add_documents(kb_id, chunks)
    RagSvc->>RagSvc: 批量调用 Embedding 模型生成高维向量
    RagSvc->>RagSvc: 向量 L2 归一化 (L2 Normalization)
    RagSvc->>FAISS: faiss_index.add(vectors) 追加二进制向量
    RagSvc->>Meta: 更新 metadata.json 记录 Chunk ID 与文本来源
    RagSvc->>RagSvc: 执行 faiss.write_index 保存物理磁盘
    RagSvc-->>API: 构建完成通知
    API-->>Admin: 返回成功推送到知识库 `kb_id`
```

### 2. 问答检索与 LLM 生成流程 (RAG Query Workflow)

```mermaid
sequenceDiagram
    autonumber
    actor User as 用户/客户端
    participant WS as WebSocket / HTTP Engine
    participant Guard as Guardrails 护栏
    participant RagSvc as RagService (FAISS + BM25)
    participant Search as WebSearchService (若开启联网)
    participant LLMProxy as LLM Tool Proxy (/api/llm-proxy)
    participant LLM as LLM API (OpenAI/LM Studio)
    participant Hist as HistoryService

    User->>WS: 发送提问 Query ("Java 线程池原理")
    WS->>Guard: 执行 input_guardrails (脱敏 + 防注入)
    Guard-->>WS: 返回安全 Query
    
    par 并行检索
        WS->>RagSvc: 稠密向量检索 (FAISS Index Search)
        WS->>RagSvc: 稀疏字面检索 (BM25 Token Search)
    end
    
    RagSvc->>RagSvc: 执行 RRF (Reciprocal Rank Fusion) 倒数排名融合打分
    RagSvc->>RagSvc: 得分阈值过滤 (Similarity Threshold Filter)
    RagSvc-->>WS: 返回最相关 Top-K 参考 Chunk 列表

    opt 若用户开启联网搜索模式
        WS->>Search: 调用 extract_keywords 提炼精准搜索词
        Search->>Search: 抓取 Bing/Baidu 并执行三维降噪
        Search-->>WS: 返回高质量网页补充摘要
    end

    WS->>WS: 动态构建 System Knowledge Prompt (结合 Strict KB 规则)
    WS->>LLMProxy: 发起流式 Chat Completion 请求
    LLMProxy->>LLM: 转发代理请求 (自动格式补全)
    LLM-->>LLMProxy: 返回 SSE 流式 Chunk / 思考链 <think>
    LLMProxy-->>WS: 转发 SSE 文本流
    WS-->>User: 实时推送回答 Token

    WS->>Hist: 会话结束，异步落盘对话与引用 Chunk 到 history.json
```
